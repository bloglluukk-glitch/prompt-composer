# Contributing

[Korean](CONTRIBUTING.md) | **English**

Update Korean and English documents together. New cards should state an observable intention, names and clauses in both languages, commonly confused roles, official background links, and unverified behavior. Preserve the components of derived concepts; do not label them as independent official features.

Add examples with equivalent meaning in both languages and run [the validator](validate_prompt_composer.py). Use fictional subjects. Test alternative phrasings of the same intention rather than tailoring an alias only to one example sentence.

For real generation results, match models, inputs, and settings between baseline and Composer variants. Retain successful and unsuccessful results, execution counts, and failure criteria. Passing a composition test is not evidence of model quality.

Do not attach personal information, client materials, secrets, unlicensed photographs, or the text of official documents. Review ordinary output in `outputs/` and explicitly select only reviewed files for publication. You must have permission to share contributions under this package's [MIT License](LICENSE).
