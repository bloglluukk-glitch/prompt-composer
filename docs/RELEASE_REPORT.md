# Prompt Composer 공개 보고서

**한국어** | [English](RELEASE_REPORT.en.md)

버전 0.1.0 · 검수일 2026-10-06 · [공개 저장소](https://github.com/bloglluukk-glitch/prompt-composer)

## 무엇을 공유하는가

감각적인 요청을 소재·빛·움직임·초점·시간·보존 조건으로 나누고, C4D와 Redshift에서 얻은 판단 구조를 한·영 제작 프롬프트로 조합하는 오프라인 도구다. 짧은 프롬프트와 상세 프롬프트, 선택·제외 근거, 출처, 불확실성, 상대 시간 계획을 함께 제공한다.

예를 들어 “새틴 금속 제품 위로 빛이 지나가며 얇은 코팅 반사를 드러내기”를 입력하면, 방향성 하이라이트 이동·거칠기·별도 코팅 반사·광원 크기를 조합한다. 요청한 5초·24fps·16:9 및 형태·로고 보존 조건을 상세 프롬프트에 유지한다. 코팅을 제품 전체의 투과로 잘못 치환하지 않도록 구성했다.

## 공개 파일 40개

| 구성 | 파일 수 | 내용 |
| --- | ---: | --- |
| 실행·검증 | 4 | 실행 코드, 검증 코드, 설정 JSON, 메모리 안에서만 쓰는 추적 SQL |
| 공개 지식 | 2 | 지식 카드 23개, 공식 배경 출처 9개 |
| 한·영 입력 예제 | 12 | 코팅 리빌·SSS 역광·미세 표면·초점 이동·안개와 빛줄기·상대 타이밍 각 2개 |
| 실제 조합 결과 | 3 | 예제 12건의 JSON 기록과 코팅 리빌 한·영 읽기용 결과 |
| 입력 템플릿 | 1 | 사용자가 내용을 채워 쓰는 JSON |
| 한·영 문서 | 14 | 소개·사용법·구조·출처·기여·변경 기록·본 보고서 각 2개 |
| 검증 기록 | 1 | 실행 검사 결과와 검증 범위 |
| 공개 관리 | 3 | MIT License, 제외 규칙, 파일별 SHA-256 명세 |

Motion 4개와 Redshift 19개를 첫 공개 범위로 선별했다. 개인 지식 저장소 전체나 전체 60개 카드는 공개하지 않는다. 다른 사람은 Python 3.11 이상에서 추가 패키지·C4D·Redshift·개인 데이터베이스 없이 실행할 수 있다. 실행 확인 환경은 Windows, Python 3.12.14이다. [전체 명세](../UPLOAD_MANIFEST.json)

## 시험한 것

- 기능 검사 20/20 통과, 한·영 예제 조합 12/12 통과.
- 여섯 언어 쌍에서 동일한 지식 카드 선택, 예제 영문 프롬프트의 한국어 잔여 없음.
- 요청한 화면 비율·시간·프레임률·보존·제외 조건 유지; 미입력 수치와 커브 동작을 임의 생성하지 않음.
- 관련 없는 일반 단어의 과잉 선택, SSS와 투과 혼동, 파생 빛줄기의 구성요소 누락 검사.
- 별도 작업 폴더와 새 복사본에서 실행; 기존 출력 덮어쓰기 방지; 네트워크 및 예제 이미지 접근 없음.
- 저장된 결과 파일을 입력 예제로 잘못 읽던 문제도 수정하여 결과 포함 배포본으로 재검사했다.

## 공개 전 검수와 제외 범위

공개 대상 40개 파일의 텍스트·JSON·문서 링크·파일 목록을 확인했다. 실제 개인 연락처·PC 사용자 경로·인증정보 패턴은 발견되지 않았다. 공개 저자 표시는 GitHub 계정 이름만 사용하며 커밋 이메일은 GitHub 비공개 이메일 주소를 사용한다. 원본 파일은 별도 해시 비교로 보존을 확인했다.

개인 SQL 원본, 환경 변수 파일, 계정·인증 파일, 내부 운영 기록, 고객 자료, 실제 이미지·영상, 기존 비공개 작업 이력은 업로드 대상에서 제외한다. 예제의 이미지 이름은 역할을 설명하는 자리표시자이며 실제 파일은 포함하지 않는다. 새 저장소는 검수된 파일만 담은 새 이력으로 시작한다.

공식 Maxon 문서는 배경 출처로 연결하며 문서 본문이나 스크린샷을 배포하지 않는다. 공개 문구는 작업 판단과 실험 가설로 다시 작성했다. MIT License는 이 공개 패키지에만 적용하며 외부 문서·상표·소프트웨어는 포함하지 않는다. [출처와 주장 범위](../SOURCES.md)

## 아직 확인하지 않은 것

실제 생성 모델 호출과 렌더 비교는 **0건**이다. 생성 성공률, 물리적 정확성, 정확한 F-Curve 재현, 특정 모델의 설정 지원을 보장하지 않는다. 점수는 선택 규칙의 순위이며 성공률이 아니다. 상대 시간의 다섯 단계는 편집 제안이다. C4D 플러그인이나 장면 생성기는 아니다.

영문 출력은 등록된 지식 문구를 조합하며 임의의 한국어를 번역하는 일반 번역기는 아니다. 등록되지 않은 한국어 피사체는 중립적인 영문 표현과 불확실성 안내를 사용한다. 원래 입력한 추가 조건은 별도 보존되므로 새로운 요청은 결과를 검토해야 한다.
